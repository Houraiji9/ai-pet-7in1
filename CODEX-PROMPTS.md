# 桌宠素材 Codex 提示词（本地 Codex 用）

每个角色要出 3 张图：①定稿形象 idle ②左走 walk ③被拎起 drag。
参考图：AI-Fanworks 的 `<角色>-Chibi.png`（Claude / Gemini / GLM / Kimi / Grok）。
把 `<ROLE>` 换成角色英文名（claude、gemini、glm、kimi、grok），保存位置按需改。

## ① 定稿形象（附参考图 <角色>-Chibi.png）
Use your built-in image generation tool to create ONE image and save it as design/<ROLE>/idle.png. Redraw the attached chibi character as faithfully as possible (same face, hair, accessories, logo ornaments, outfit, wings/tail or other features, art style and chibi proportions), with only these changes: neutral standing idle pose facing viewer with both hands relaxed in front, NO props, NO sparkles or effects, full body with feet visible, centered, portrait canvas 576x1024, on a solid flat pure green #00FF00 background with no shadow and no text.

## ② 左走（附上一步的 idle.png）
Use your image generation tool. Using the attached image as the exact character model sheet, generate ONE new image of the SAME chibi character (identical face, hair, accessories, logo ornaments, outfit, short chibi legs, shoes, and any wings/tail) in a SIDE VIEW walking pose, facing and walking toward the LEFT side of the image (her nose points to image left), mid-stride with one foot forward, arms swinging gently, happy expression. Full body, same scale and canvas size 576x1024 portrait as the reference, feet near the same bottom position, solid flat pure #00FF00 green background, no shadow, no ground, no other objects, no text. Save it as design/<ROLE>/walk.png

## ③ 被拎起（附 idle.png）
Use your image generation tool. Using the attached image as the exact character model sheet, generate ONE new image of the SAME chibi character (identical face, hair, accessories, logo ornaments, outfit, short chibi legs, shoes, and any wings/tail) being lifted up by an invisible hand from the back of her collar: front view, body hanging slightly, short legs dangling in the air with feet apart and toes pointing down, arms raised a little and flailing, flustered surprised expression with small sweat drop. Full body, same scale, canvas 576x1024 portrait, character centered, solid flat pure #00FF00 green background, no shadow, no hand visible, no other objects, no text. Save it as design/<ROLE>/drag.png

出完把 15 张图传给星织，动画、抠图、导出由星织做。
